# Internship-application-tracker
A beginner-friendly Python command-line application to track internship applications, deadlines, stipends, and statuses.
## Features

- Add an internship application
- View all saved applications
- Store company name, role, stipend, deadline, and status
- Track application progress such as Applied, Interview, Rejected, or Selected

## Technologies Used

- Python
- Jupyter Notebook
- Lists and dictionaries
- Functions
- Conditional statements and loops

## How to Run

1. Download or clone this repository.
2. Open `internship_tracker.ipynb` in Jupyter Notebook.
3. Run the cells in order.
4. Use the menu to add and view internship applications.
